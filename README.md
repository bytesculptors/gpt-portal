## Description

A chat application which is similar to ChatGPT with streaming answering using OpenAI key.
Tech stack: NestJS, PostgreSQL

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev
```

## Test

```bash
# e2e tests
$ npm run test:e2e
```
